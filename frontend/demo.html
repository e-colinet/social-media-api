🔄 Génération automatique des modèles

Le frontend utilise un système unique de génération automatique des modèles à partir du fichier OpenAPI :

Générer les modèles :

npm run generate-models

Vérifier la synchronisation :

npm run check-models

Cette approche garantit que le frontend reste toujours synchronisé avec l'API backend, même lors de modifications du schéma.
